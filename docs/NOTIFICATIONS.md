# 收益通知

数据来自已落盘的结算记录（`runs/session_rewards.jsonl`），不 OCR、不碰设备。
开关是 `notify.quota_done`：

- **打工学习日报**：学习+打工当天都跑完时推，逐次列出每节课、每次打工的收益。
- **冒险日报**：每天 23:59 推，冒险一天几百次，所以只给指标表、不列逐次。

## 打工学习日报

Telegram 里是**原生表格**（Bot API 10.1+ 的 Rich Messages，带框线与斑马纹、数字列右对齐）：

```
🐾 2026-10-10 打工学习日报

今日学习 学分 +231 力量 +216 / 魅力 +0 / 智力 +0
┌────────┬──────────────┬──────┬──────┐
│ 时间   │ 课程         │ 学分 │ 力量 │   ← 数字列右对齐
├────────┼──────────────┼──────┼──────┤
│ 00:01  │ 武术身法课   │  +30 │  +26 │
│ 09:58  │ 武术身法课   │  +30 │  +26 │
└────────┴──────────────┴──────┴──────┘

今日打工 工分 +378 金币 +3776
┌────────┬──────────────────┬──────────┬──────┬──────┐
│ 时间   │ 岗位             │ 雇佣     │ 金币 │ 工分 │
├────────┼──────────────────┼──────────┼──────┼──────┤
│ 03:54  │ 城区护卫委托(45分钟) │ 张二狗   │ +550 │  +54 │
│ 09:12  │ 城区护卫委托(45分钟) │ 杨小喵   │ +531 │  +54 │
│ 10:12  │ 城市采风写生(45分钟) │ 被张二狗雇 │ +357 │   +3 │
└────────┴──────────────────┴──────────┴──────┴──────┘
```

结构就这五段：标题行 / 学习汇总行 / 学习表 / 打工汇总行 / 打工表，**其余文案都没有**
（不带时长、合计行、平均值，也不带通知标题）。「雇佣」列是这次雇了谁，两种方向语义相反：
直接写名字 = 我们雇了对方（加成归我们），「被XX雇」= 对方雇了我们、加成被对方拿走。
「看视频」补贴不在通知里显示（数据照常记录，仪表盘收益记录页可查）。

表格是 Telegram 自己画的（`sendRichMessage` 的 `<table bordered striped>`），不是图片、
也不是等宽代码块。飞书/桌面/OnePush 没有富消息，会自动把同一份内容剥成一行一条的纯文本。
表格只列当天真出现过的属性列；一天超过 30 条只列最近 30 条（完整明细在仪表盘
「日志 → 收益记录」页）。

## 冒险日报

跟总账口径不同——冒险一天几百次，逐次列会刷屏，所以给的是**指标表**
（不带通知标题，正文首行自报家门）：

```
🧭 2026-10-10 冒险日报
┌────────┬──────────────────────────────┐
│ 指标   │                         数值 │
├────────┼──────────────────────────────┤
│ 总次数 │                      491 次  │
│ 金币   │                       +5465  │
│ 心情   │                       +2630  │
│ 清洁   │                        +730  │
│ 体力   │                        +590  │
│ 命中率 │                          36% │
│ 平均每次│                      +11.1  │
└────────┴──────────────────────────────┘
```

心情/清洁/体力是冒险的属性收益（除金币外唯一能确定的产出），
未解析出来时显示 `—` 而不是 `+0`。命中率只给百分比，不带“有收益/空手”的括号明细。
