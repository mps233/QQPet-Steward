# 官方「职业树」页面规格（真机实测）

> 采集：2026-10-19，一加 9 Pro（1080×2412 / density 2.25 → 逻辑画布 **480×1072 dp**），
> QQ 9.3.65。全部数值由截图**像素实测**换算成 dp（1 dp = 2.25 px），不是目测。
> 参考截图归档在 `qqpet_assets/_raw/career_tree/`（3 张整页 + 8 张弹窗 + 1 张 toast）。
> 图标素材抠好放在 `static/qp-icons/career/<职业线>_<层级>.png`（40 个）。

## 0. 一句话结构

**顶部固定头（返回 + 标题 + 三属性胶囊 + 一行副标题）+ 可横向滑动的 8 线 × 5 级矩阵**。
每条职业线是一列，从上到下 见习 → 初级 → 中级 → 高级 → 大师；列内相邻格子用细竖线连起来。
**点格子 → 弹出居中大卡片**（图标压在卡片顶边上）或**顶部弹一条 toast**。

### 2.3 单元格的四种状态

| 状态 | 图标 | 名字牌 | 按钮 |
| --- | --- | --- | --- |
| **占位**（该级根本没有职业） | 只有描边的六边形 + 大「?」 | 深棕胶囊 + 「???」 | 无（点了什么都不发生） |
| **未解锁** | **灰色**立体六边形 + 灰色职业物 | 深棕胶囊 `rgb(85,63,59)` + 白字 | `去打工` |
| **已解锁** | **彩色**六边形 + 彩色职业物 | 深棕胶囊 + 白字 | `展示` |
| **已展示**（当前佩挂） | 彩色 + **金色外发光描边** | **黄色胶囊** + 深棕字 | `已展示`（次级样式） |

名字牌几何：实测 181–336 × 799–861 px → **69.3 × 33.8 dp**，圆角 = 高/2，居中于列。
名字牌与图标之间有一条**细竖线**（宽约 4 px = 1.8 dp，`rgba(255,255,255,.10)`）。
**连线颜色的判据（2026-10-19 逐像素核对，改前必读）**：

| 现象 | 真实语义 |
| --- | --- |
| 连线**金色** `rgb(255,240,78)` | 这一级**已解锁** |
| 名字牌**亮黄** `rgb(255,240,78)` | 这一条线**当前展示（佩挂）中** |
| 连线暗灰 `rgb(69,69,69)` | 这一级未解锁 |

证据：武术家连升 4 级、四段连线全金，但它的名字牌是深棕 `rgb(85,63,59)`（不是展示中）；
画家见习是展示中（黄牌），而它下面那段连线却是暗灰。
**两件事互不相干，别用一个状态位同时驱动。**

### 2.4 当前宠物实际数据（2026-10-19 实测）

- 8 条线 **见习全部已解锁**
- 「画家」见习 = 涂鸦小徒 → **已展示**（黄牌 + 金框）
- 「武术家」是隐藏线，**见习～高级 4 级全部已解锁**（武道宗师），连线是金色
- 「流浪散人」只有见习一级（小乞丐），初级及以上是占位
- **大师级全部是占位**：游戏里该级职业「还未现世」，点击弹 toast
- 其余 7 条线的 初级/中级/高级 = 未解锁灰色

## 4. Toast（点不可点 / 未投放的格子）

实测色块：**深棕黑圆角矩形** `rgb(46,35,32)`，居中，距顶约 51.8%，
圆角 ≈ 高/2，白字 15dp，内边距约 20×12dp，停留 ≈ 2 秒。

三条原文（来自 jadx 反编译 `i5/a.java` 的 `i()`，与实测 toast 一致）：

| 条件 | 文案 |
| --- | --- |
| 大师级未投放（level 500） | `该职业还未现世，再观望一下` |
| 大明星线（careerType 8）高级 | `听说努力就可以悟出真谛` |
| 其余锁死的格子 | `大师只收有极致天赋的学徒` |
| 空数据格子（占位） | 无提示，静默忽略 |

## 5. 交互补充

- 横滑：整条矩阵一起横移，顶部头固定不动
- 点关闭 × 或系统返回 → 关弹窗（返回键第一次只关弹窗，第二次才退页面）
- 弹窗打开时背景整体压暗，矩阵不可点
- `展示` 会把该职业设为当前佩挂：主页面头像旁的名字标签换成该职业图标 + 名称（实测从 `武道宗师` 变 `涂鸦小徒`）

## 7. 实测补充：流浪散人列有"空格"

像素扫描（每列每行取 cy±95、cx±80 的窗口，统计与背景的色差占比）：

| 线 | 见习 | 初级 | 中级 | 高级 | 大师 |
| --- | --- | --- | --- | --- | --- |
| 流浪散人 | 0.74（有格子） | **0.00** | **0.03** | 0.10（? 占位） | 0.10（? 占位） |
| 画家 | 0.88 | 0.68 | 0.71 | 0.71 | 0.10 |
| 其余 6 线 | 0.74 | 0.62~0.70 | 0.64~0.77 | 0.66~0.71 | 0.10 |

（0.10~0.12 = 只有描边六边形 + 「?」的占位格；0.00~0.03 = 连格子都没有，只有贯通的长竖线）

→ **存在第五种状态 `empty`**：整格不渲染，只有列内那条竖线穿过去。
流浪散人 = `[见习, empty, empty, placeholder, placeholder]`。
点击 `empty` 格无任何反应（对应反编译 `openItemDetail` 里 `if (cVar.f692l) { skip: blank item }`）。

把这份矩阵补进 `web/src/lib/career-tree.ts` 的 `TREE` 时，初级/中级两格必须标 `empty`，
不能按"未解锁灰格"渲染 —— 灰格有六边形和名字牌，空格没有。
